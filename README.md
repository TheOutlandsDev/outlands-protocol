# OUTLANDS Protocol

A research-stage project for an account-based proof-of-work Layer 1 protocol.

**Current public contents: this project overview only.** No protocol
implementation, node, wallet, testnet/devnet software, tests or executable
release is published in this repository yet. Treat it as a project placeholder,
rather than a reference implementation you can build or run.

The intended scope is the original OUT account-based proof-of-work protocol
and a future testnet/devnet reference implementation. Published source, build
instructions, tests and explicit licensing will be needed before readers can
evaluate that implementation.

For tools with published implementations, examples and tests today, see
[OUTLANDS Game Tools](https://github.com/TheOutlandsDev/outlands-game-tools)
and [IW4x Bot Warfare Extras](https://github.com/TheOutlandsDev/iw4x-bot-warfare-extras).
Read each project's validation notes for its tested scope and remaining gaps.
